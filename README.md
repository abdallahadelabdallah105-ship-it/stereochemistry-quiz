# اختبار الكيمياء الفراغية (Stereochemistry Quiz - Lec 1 & 2)
### إعداد وإشراف: Dr. Robbe (Helwan University)

اختبار تفاعلي يغطي موضوعات الكيمياء الفراغية وتسمية المركبات العضوية (CIP Rules, E/Z, Cis/Trans, Stereoisomers).
- إجمالي الأسئلة: 15 سؤال مع التفسير العلمي والشرح الفوري.
- نظام التتبع: مربوط تلقائياً بـ Google Sheets لحفظ اسم الطالب، الدرجة، والأسئلة غير الصحيحة.
